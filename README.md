A deterministic program that writes a single 126-character code-review comment approving a pull request with quiet existential dread, for make.fun's "Two Days of Quiet Dread" bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
